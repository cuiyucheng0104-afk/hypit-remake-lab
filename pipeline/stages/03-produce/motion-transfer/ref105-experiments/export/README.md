# ref105 重制 · 外部平台生成交付包

用途：在你自己的视频平台上**逐段做视频编辑**（以原片分段为底，换人换景、动作一比一），生成完放回
`generated/`，再由 `conform.py` 按原片时间线装回去。拆解依据见
`../../../references/ref-105/ANALYSIS.md`、`TIMELINE.md`。

## 目录

| 路径 | 内容 |
| --- | --- |
| `refclips/S01.mp4` … `S09.mp4` | 9 段参考视频：按真实剪辑切点切分，已裁掉底部字幕条（1280×620），已抹掉抖音 logo、抖音号、"Q 坚果"、作者署名和片尾落版圆环；无音频 |

| `thumbs/S01.jpg` … | 每段 12 格缩略图，方便对照 |

| `conform.py` | 回装脚本 |
| `generated/` | 你把生成结果放这里 |

## 在平台上每段怎么提交

1. 模式选**视频编辑 / 视频重绘**（以参考视频为底、保持时长），不是"参考生成"。
2. 按顺序上传：`characters/` 里的图片1–4，再上传 `refclips/Sxx.mp4` 作为视频1。
   不用反派头目的段，可以不传图片2，但**编号要跟提示词一致**。
3. 粘贴 `prompts/Sxx.txt`。平台的引用写法不同时整体替换：`@图片1`→`@image1` / `[图1]`，`@视频1`→`@video1`。
4. 时长选"跟随参考视频"；画幅选自适应；分辨率建议 1080p。
5. 每段可多抽几次，挑动作最贴原片、人物最稳定的一条。
6. 下载后**改名为段号**放进 `generated/`：`generated/S01.mp4` … `S09.mp4`。

平台如果限制参考视频不超过 10 秒，S02–S05 需要再对半切。告诉我限制是多少，我按切点重切。

## 装回去

```bash
python3 conform.py
```

- `out/conformed.mp4`：1280×620、30 fps，和原片正片逐帧对齐。
- `out/conformed_720.mp4`：底部补 100 px 黑条，留给字幕。
- `out/compare.mp4`：上面原片、下面新片，逐段对照检查动作还原度。
- 缺的段自动用灰度原片占位，可以边生成边装。生成结果时长和原片差超过 0.04 s 时，会按比例变速对齐，并在输出表里标出来。

## 之后交回给我

1. 生成好的 `generated/*.mp4`（发给我或直接放进目录都行）。
2. 在 `captions-template.srt` 里写好新字幕，或者告诉我方向，我来写。
3. 配乐：原片配乐不能用，给我一首你有版权的曲子，或者让我按原片节奏选方向。

我用 Hypit 做最后合成：按原片的字幕系统（底部黑条、白色书法字、模糊入场、渐隐出场）加上新字幕，
配乐按原片"全程压满、85 s 骤停"的结构混音，最后渲染成片交付。
