# ref105-s01-clone · Treatment

一个人，一院子的斗笠刀客，雨。前三秒是两张脸的对视：他的冷静，对面一片压低的斗笠。第三秒他把剑翻成倒握——字幕同时告诉观众"惩恶不杀"——俯拍把他缩成台阶上的一个点，隔着人群远远对峙。随后刀客嘶吼扑来、他纹丝不动、手一紧，镜头贴地跟着他冲进人群，最后在木格窗前用倒握的剑格挡、擒拿、旋身、再挡。

**保留原片的**：13 镜的顺序、景别、机位与每一刀的切点帧（卡音乐拍）；下方黑条与两句字幕（原文、原时间、第二句模糊进场、两句都渐隐出场）；原声铺底；青蓝冷调、木格窗逆光。

**因换人而改的**：原片斗笠檐压画面的特写（A、D、J）改为湿发垂额、雨丝与眉骨旧疤撑起画面上沿；主角近黑长袍在冷调里靠暗银暗纹和轮廓光立住，不再靠亮蓝袍抢色——亮色让给刀客斗笠边缘的水光和木格窗的逆光。原片"一群束发黑衣人"改为斗笠刀客：斗笠压低遮眼，更像一片无脸的人墙，反打更强。

**倒握剑是这一段的题眼**：E 镜翻剑成倒握（刃贴前臂）、F 俯拍手中倒握、K 倒握的手一紧、M 竖起倒握的剑格挡——每一镜都要明确演出倒握。

**生成分组（按叙事，每组一次 H3 请求，每镜多生成一些以便剪到原切点）**：
1. 立局（A–D，≈5 s）：主角近景 → 刀客侧脸群像 → 高角度人群 → 主角面部特写
2. 倒握（E–G，≈4 s）：翻剑成倒握的手部特写 → 正顶俯拍 → 隔人群远景
3. 冲锋（H–K，≈5 s）：奔跑腿部碎片 → 刀客嘶吼扑来 → 主角面部特写后甩出 → 倒握的手一紧
4. 开打（L–M，≈5 s）：贴地跟拍冲入人群 → 木格窗前格挡、擒拿、旋身、再挡

**拼装**：每组生成后找出它自己的切点，逐镜选取最有表现力的一段，按原片帧数截取（必要时轻微变速），放回原片切点帧。
