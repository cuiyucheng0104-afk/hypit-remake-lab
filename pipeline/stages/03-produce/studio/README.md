# Hypit Studio（员工用的画布网页）

挂在 5090 的 ComfyUI 端口上：**http://<5090内网IP>:8188/studio**。不用装任何东西，浏览器打开就能用；所有任务进 ComfyUI 同一个队列、共用一张显卡。测试阶段**没有登录**（之后再加）。

## 能做什么

| 卡片 | 模型 | 用法 |
| --- | --- | --- |
| 🖼 图片生成 | Qwen-Image 2.1 int8（审查版 / 未审查版可切换） | 不连图 = 文生图；连 1–6 张图 = 图生图 / 多图参考；可开「提示词扩写」（Qwen3.5-9B PE） |
| 🎬 视频生成 | MiniMax H3 int8（FL2VA / Ref2VA） | 文生视频、图生视频（首帧 / 首尾帧）、参考生视频（图·视频·音频）、多参考（关键帧钉到第几秒）、续写（取视频最后一帧接着拍）；可选加速 LoRA、二采高清、任意叠加本机 LoRA（动作·打斗·文戏、研究用） |
| ⬜ 视频转白膜 | SAM 3D Body + 自写去重影节点 | 真人视频 → 0.78 灰白模视频 + 叠原片核对视频 + GLB |

画布是 React Flow：素材 / 生成结果右边的圆点拖到生成器左边对应接口就是输入；生成结果会出现在生成器右边，还能再连到下一个生成器（生成的图 → 图生视频，生成的视频 → 续写 / 白膜）。画布存在服务器 `ComfyUI/user/studio/canvases/`，每次提交记在 `ComfyUI/user/studio/jobs.jsonl`。

## 目录

- `hypit_studio/` —— ComfyUI 插件，部署到 `ComfyUI/custom_nodes/hypit_studio`
  - `__init__.py`：`/studio` 页面和 `/studio/api/*`（选项、提交、查进度、画布存取）
  - `graphs.py`：把表单拼成 ComfyUI API 任务（结构对照官方模板 `video_minimax_h3_*`、`image_qwen_image_2_1_*` 和 LBH 二采示例）
  - `qwen_pe.json`：Qwen 提示词扩写的系统提示词（取自官方模板）
  - `sam3d_whitebox.json`：白膜任务模板（由「SAM3D白膜-灰底」工作流导出）
  - `web/index.html`：打包好的单文件网页（JS/CSS 全内联，内网电脑不需要外网）
- `web-src/` —— 网页源码（React 18 + @xyflow/react 12 + Vite），`npm run build` 输出到 `hypit_studio/web/`
- `deploy.sh` —— 打包并复制到 5090：`./deploy.sh ROG@<5090内网IP>`
- `make_workflows.py` —— 用 `graphs.py` 重新生成 ComfyUI 侧边栏里的 H3/ 与 H3-研究用/ 共 12 个工作流（参数和网页完全一致）

## H3 画质设置（2026-10-26 对照 YZ 金鱼整合包优化）

原来照官方模板默认 0.4 百万像素（864×480）、544p 版加速 LoRA、int8 视频 VAE、默认码率输出，画面发软、衣服上有梳状条纹。现在：

| 项 | 原来 | 现在 |
| --- | --- | --- |
| 加速 LoRA | fl2v 8 步 v1.0 / ref2v 4 步 v0.1（544p 训练） | lightx2v **768p 版 v1.1，8 步**（fl2v、ref2v 各一个），shift 6/3，euler |
| 默认清晰度 | 0.4 MP（864×480） | **0.9 MP（1280×736）**，最高 1.5 |
| 视频 VAE | int8_convrot | **fp16** |
| 输出 | SaveVideo auto | **H.264 CRF 16** |
| 二采 | 先 0.25 MP 半程出片 → 放大 → 0.90 起精修；图生 / 续写 / 多参考开二采会报错 | 先完整出片 → 潜空间 ×1.5（按放大后尺寸**重建条件**）→ Turbo 网格最后两步 0.667/0.462 精修；五种方式都能开 |

| RTX 超分 | 无 | 可选「RTX 超分 ×2」（Comfy-Org/ComfyUI_Nvidia_VFX_Nodes，nvidia-vfx，ULTRA）：解码后像素空间每边 ×2，只锐化不改内容；和二采一起开约 4K（长边上限 3840）。节点没装时网页不显示这个开关 |

5090 实测（3 秒片段）：默认 0.9 MP 约 45–50 秒；RTX ×2（2560×1472）约 70 秒；二采 + RTX（3848×2144）约 70 秒；二采到 1952×1088 约 50–100 秒（参考视频 / 多参考约 3 分钟）。

## 白膜修正（2026-10-26）

- 「只要主角」原来是让 SAM3 只追 1 个人（max_objects=1），实测会锁到背景路人、还在几个人之间跳。现在一直追所有人，交给去重节点的 `main_only`：从画面最大的几个人偶出发逐帧跟住位置和大小都连贯的那个，取覆盖最多的一条；主角糊到认不出的帧就空着。
- 去重节点原来只按框重叠（IoU）认领，甩开长袍的主角真人框比身体大太多，**整个被删掉**；现在人偶 70% 以上落在真人框里且不太小也算认领，小框先认领。
- GLB 动画帧率改成跟源视频（原来固定 24，30fps 素材会变慢）；白膜视频改 H.264 CRF 16。
- 测试素材（Mixkit 免费素材）：功夫长袍、跆拳道踢腿、多人逆光奔跑、群战快动作，多人 / 只要主角两种模式都看过核对视频。
