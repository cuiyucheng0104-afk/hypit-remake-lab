## 它是什么

一条抖音企业号教程：讲解员出镜两秒交代主题，然后切到俯拍手机，一只手按步骤操作，配音逐步讲解
「企业蓝V认证」的新流程。每一步都用红色箭头或红圈把观众的视线引到要点的位置。

## 为什么有效（解读）

1. **问题式标题一直挂在顶上**：黄字黑描边的两行大标题「#新的企业蓝V认证 / 如何认证？」全程不动，
   观众任何时刻进来都知道这条在讲什么。
2. **真人开场建立信任，然后立刻进入操作**：讲解员只出现约 2 秒（「这边是新版蓝V的认证，我带大家操作一遍」），
   2.1 秒硬切到手机，不浪费时间。
3. **指引跟着话走**：说到「点右上角的三条杠」时红箭头出现在手机右上角，说到「企业服务中心」时箭头跳到那一项；
   说到「这个确定是你原先的那个抖音号」时手绘红圈圈住账号。**箭头和红圈的出现时刻由台词决定**，
   而且会跟着被移动的手机走。这是 Hypit「事件锚在词上」最直接的用例。
4. **提醒式口播**：「一定不要选错」「如果你点新的就从 0 开始，连粉丝都没有了」，把最容易出错的一步讲透。
