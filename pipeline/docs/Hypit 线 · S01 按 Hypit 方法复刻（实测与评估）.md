# Hypit 线 · S01 按 Hypit 方法复刻（实测与评估）

> 上一次（[[Hypit · 通用复刻骨架 remake-kit]]，已废弃）用自写脚本替代了 Hypit 方法：一次生成整段、不拼装、没字幕。本次按 Hypit Skill 完整方法重做。工程：`~/hypit-projects/productions/ref105-s01-clone/`。

## 流程（实际执行）
1. 读 Skill 说明 14 篇（读片、改编、系统、时间线、媒体、表演、轨道、文字、独立媒体、短剧、生成依赖、审片、截帧、构建）。
2. 逐帧读 S01（249 帧 11 页）+ WhisperX 转写（确认无人声）+ 原尺寸帧量字幕条（y 640–720）与字幕字形 → 写进 `references/ref-105/TIMELINE.md`。
3. BRIEF / TREATMENT。
4. 手写 SVML：13 个空 Segment、每镜 Transform→Normalize→SemanticTake、Timeline 按原切点帧放置；画面区 1280×640 + 黑条；`ma-shan-zheng` 字幕两句（第二句模糊进场、两句渐隐）；原声 audio-track。
5. **先用原片画面占位**构建预览（免费）验证结构 → 4 组 H3 请求（5+4+5+6 s，按叙事分组、每镜多生成）→ 逐组找切点、逐镜选段 → build-record 固定 → 拼装构建。

## 结果
- 13 刀切点落在原片帧上（卡原声节拍）；无黑帧。~~15 个同时间点对照每格景别机位一致~~ → 复盘更正：静态抽帧看着像，逐镜比对后 C/D/F/K/L 景别或机位不对位（见下方「复盘」）。
- 主角 6 次出镜形象一致（束发、暗纹黑袍、眉骨疤）；斗笠刀客一致。
- 未达成：**倒握剑**（字幕的所指）没演出来；色调偏灰；动作能量、甩镜、运动模糊弱于原片；M 镜取 2.9 s 生成段 ×1.5 变速。

## 评估
- **结构层**（切点、字幕、声音、镜头类型）已能稳定复刻，这正是 Hypit 的强项：Segment + 按帧放置 + 固定生成结果，改剪辑不花生成钱。
- **内容层**的短板在生成模型：具体手部动作（倒握）、打斗接触、运动模糊/甩镜，H3 靠文字提示难以精确 → 需要参考图（先用 Seedream 生成倒握首帧）或自有服务器的动作参考视频。
- **钱主要花在 Claude 上，而不是生成**：生成 ¥1，Claude 折合 ¥94。每部复刻片**开新会话**（上下文 < 10 万）可把 Claude 成本降到约 1/5–1/10。
- 市场 H3：单任务 6–9 分钟，偶发排队 8 分钟；多组并行后墙钟 ≈ 最慢一组。
- 按此估算 ref105 全片 9 段：生成约 ¥9–15（含重做），新会话下 Claude 约 $20–40，墙钟约 3–4 小时。

## 复盘：切点对了，镜头里面和镜头之间没对（2026-10-01）

证据：`productions/ref105-s01-clone/drafts/review/`（逐镜三帧对照 shots_A-G / shots_H-M、逐帧 ambig、stats.json）。

**切点本身没问题**：`hypit media boundaries` 对原片 0–8.3 s 给 16 个候选，12 个就是真实切点（=13 镜），另外 4 个逐帧核对是镜内事件——23f 闪电、I 镜和 M 镜里的甩镜。8.3 秒 13 镜，平均 0.64 秒一镜，最短 7 帧。

**复刻片的问题**：
1. **主角没有视觉锚点，"一对众"丢了**：原片主角是全场唯一的亮蓝袍 + 斗笠，敌人一片黑；复刻里主角黑袍，敌人黑袍 + 斗笠，大全景（C/F/G/L）里找不到主角，F 俯拍变成对称花纹、主角消失。Treatment 只换了外观，没保住"主角是画面里唯一亮色"这个关系。
2. **镜内没动作，13 刀变幻灯片**：镜内运动量（相邻帧差）原/复 A 7.0/1.0、J 9.9/2.3、L 19.3/7.2、I 29.2/13.9。原片的切点靠动作带过去：J 末尾斗笠甩过画面接 K，L 末尾斗笠挡镜头接 M，M 是 2 秒连续手持打斗带甩镜；复刻 J 静脸、L 背影站定、M 是摆好的格挡再 1.5 倍速。
3. **景别/机位不对位**：C 平视中远景行进 → 高机位大全景；D 中近景 → 眼部大特写；F 俯拍孤身 → 对称图案；K 暗调运动模糊的倒握特写 → 清晰双手正握；L 前景主角出招 → 主角背影站立。
4. **K 镜多了一个跳切**：复刻 162f、164f 被检出额外切点——K 的裁剪起点 4.55 s 跨过了 H3 生成片内部的一刀，前 3 帧是另一个景别。拼装后 QA 只查了黑帧和时间点，没跑 boundaries。
5. **色调与质感**：原片青蓝（A 段 RGB 61/75/79），复刻中性灰（54/56/55）；原片 J 暖光亮脸、K 暗低反差带模糊、A 有闪电，复刻一律干净锐利的"AI 质感"。
6. 倒握没演出来（E/K），已知。

**方法层根因**：
- 验收用静态抽帧判"同类镜头"，看不出运动、衔接、主角辨识度；应加 `boundaries` 对比 + 逐镜运动量 + 连续帧检查。
- 4 次生成覆盖 13 镜，每次塞 2–4 个 0.3–0.9 秒的节拍，H3 会把动作放慢摆好；选段时按"画面像不像"选，没按"切点处的动作对不对"选。
- 提示词写了每镜画面，没写每镜的**结束状态和转场手段**（甩镜、前景遮挡、闪电）。
